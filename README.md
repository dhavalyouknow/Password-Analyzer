# Password-Analyzer

A simple yet effective tool to evaluate the strength of user passwords.
The analyzer provides real-time feedback on whether a password is weak, medium, or strong, and can also auto-suggest stronger alternatives if needed.

📌 Features

✅ Analyze password strength based on:

Length

Use of uppercase & lowercase letters

Digits

Special characters

✅ Detects common patterns (e.g., 123456, password, qwerty).

✅ Provides strength score (e.g., Weak / Medium / Strong).

✅ Suggests improvements (e.g., “Add at least one special character”).

✅ Auto-generate a strong password if the entered one is too weak.
